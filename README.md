# 💱 Currency Converter

A real-time currency converter that fetches live exchange rates using an API.

## 🔴 Live Demo
[currency-converter-pied-seven-83.vercel.app](https://currency-converter-pied-seven-83.vercel.app)

## ✨ Features

- 💱 Real-time exchange rates via Fetch API
- 🌍 Support for multiple currencies
- 🏳️ Dynamic country flags for selected currencies
- ⚡ Instant conversion on currency change

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML | Structure |
| CSS | Styling |
| JavaScript | Logic |
| Fetch API | Live exchange rates |

## 🚀 Run Locally

**1. Clone the repository:**
```bash
git clone https://github.com/frontendnitin/currency-converter.git
```

**2. Open `index.html` in your browser** ✅
